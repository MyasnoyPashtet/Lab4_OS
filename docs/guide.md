# Руководство пользователя ЛР № 4

## 1. Назначение программы

Программа читает данные ЛР № 3 и строит четыре отчёта — рейтинг посещаемости, список несдавших тест, топ студентов по «Цирковому делу» и список тестов, сданных с первой попытки за указанный год. Исходные файлы используются только для чтения.

## 2. Требования и размещение файлов

Нужны Bash 4.3 или новее и утилиты `cat`, `dirname` и `sort`. В Linux используйте терминал с Bash, в Windows — Git Bash. Скрипт сохранён в UTF-8 с окончаниями строк LF.

Положите папку `labfiles-3-26` в каталог `data/` рядом со скриптом. Внутри набора должны находиться `students/groups/` и папки предметов.

```text
Lab4_OS/
├── lab4.sh
└── data/
    └── labfiles-3-26/
        ├── students/
        │   └── groups/
        ├── Пересдачеведение/
        │   ├── A-06-22-attendance
        │   └── tests/
        └── Цирковое_Дело/
            ├── A-06-22-attendance
            └── tests/
```

Дерево показано в сокращённом виде. Для дополнительного набора положите его папку в `data/` рядом с `labfiles-3-26`, сохранив ту же структуру. Форматы файлов описаны в [спецификации](spec.md#2-исходные-данные).

## 3. Запуск и выбор набора

Откройте терминал в папке `Lab4_OS` и выполните команду.

```bash
bash lab4.sh
```

Из другой рабочей директории можно передать Bash путь к скрипту, например `bash "/путь/к/Lab4_OS/lab4.sh"`. Папка `data/` ищется рядом с указанным файлом.

Сначала программа покажет список наборов. Если в `data/` только исходный набор, экран выглядит так:

```text
Выберите набор данных
1. labfiles-3-26
0. Выход
Номер:
```

Введите `1` и нажмите Enter. Если наборов несколько, введите номер рядом с нужным названием.

## 4. Главное меню

```text
========================================
     АНАЛИЗ УСПЕВАЕМОСТИ СТУДЕНТОВ
========================================

1. Рейтинг посещаемости
2. Студенты, не сдавшие тест
3. Лучшие студенты по Цирковому делу
4. Студенты, сдавшие с первой попытки

0. Выход

Выберите действие:
```

Введите номер отчёта. Группу, предмет и тест выбирайте по номерам из списков на экране. Номера в примерах относятся к исходному набору. Сверяйте их с названиями в вашем меню.

## 5. Работа с отчётами

Шаги ниже начинаются в главном меню после выбора `labfiles-3-26`. Для запуска одной командой скопируйте соответствующий пример в терминал из папки `Lab4_OS`. Команда передаст ответы в меню по одному на строку. Первое `1` выбирает набор `labfiles-3-26`, последнее `0` завершает работу после отчёта. Если список наборов изменился, сверьте первый номер с меню.

### 5.1. Рейтинг посещаемости

1. Выберите пункт `1`.
2. Выберите группу `A-06-22` под номером `19`.
3. Выберите `Цирковое_Дело` под номером `2`.

```bash
printf '%s\n' 1 1 19 2 0 | bash lab4.sh
```

Таблица показывает логин и число посещённых занятий. Строки с наибольшим числом посещений идут первыми. В примере первая строка содержит `PereskokovDS` и `17` посещений. Значение `0` означает, что запись есть и в ней нет посещений. «Нет записи» означает, что для студента отсутствует строка в файле посещаемости.

### 5.2. Студенты, не сдавшие тест

1. Выберите пункт `2`.
2. Выберите группу `A-06-22` под номером `19`.
3. Выберите `Пересдачеведение` под номером `1`.
4. Выберите `TEST-4` под номером `4`.

```bash
printf '%s\n' 1 2 19 1 4 0 | bash lab4.sh
```

В примере в таблице одна строка — `PereskokovDS` со статусом «Не сдал». Этот статус означает, что все попытки были неуспешными. Статус «Не проходил» означает, что попыток нет. Студент с хотя бы одной оценкой от `3` в этот отчёт не попадает.

### 5.3. Лучшие студенты по «Цирковому делу»

1. Выберите пункт `3`. Программа сама найдёт папку «Циркового дела».
2. На запрос «Количество студентов [10]» введите `5`. Пустой ввод означает до десяти мест.

```bash
printf '%s\n' 1 3 5 0 | bash lab4.sh
```

В примере выводятся пять мест. Первое занимает `KozlovskyE` из группы `A-06-04` со средним баллом `4.75`. Под строкой студента указаны тест, дата и оценка каждой успешной попытки, вошедшей в среднее.

### 5.4. Тесты, сданные с первой попытки

1. Выберите пункт `4`.
2. Введите год четырьмя цифрами, например `2026`.

```bash
printf '%s\n' 1 4 2026 0 | bash lab4.sh
```

В таблице показаны логин, предмет, тест и оценка. Одна строка соответствует одному тесту, у которого самая ранняя попытка была успешной и пришлась на выбранный год. В примере есть строка `GroshevAV` — `Пересдачеведение`, `TEST-1`, оценка `5`.

## 6. Ошибки и пустые результаты

| Что показывает программа | Что проверить |
| --- | --- |
| Папка наборов недоступна или список наборов пуст | Проверьте расположение `data/` рядом со скриптом и путь `data/labfiles-3-26/students/groups/`. |
| «Выберите номер из списка» | Введите номер рядом с нужным названием. |
| Файл отсутствует или недоступен | Сверьте путь из сообщения с расположением и именем файла в выбранном наборе. |
| Ошибка формата или календарной даты | Проверьте указанную строку файла по [форматам записей](spec.md#форматы-записей). |
| Для топа не найдено «Цирковое дело» или найдено несколько папок | Выберите набор, в котором есть ровно одна папка этого предмета с тестами. |
| Подходящих результатов нет | Прочитайте сообщение и при необходимости выберите другие параметры отчёта. |

## 7. Возврат в меню и выход

После отчёта нажмите Enter, чтобы вернуться в главное меню, или введите `0`, чтобы завершить работу. В списках групп, предметов и тестов `0` возвращает в главное меню. В главном меню и на экране выбора набора `0` завершает работу.
