# Спецификация ЛР № 4 — анализ успеваемости студентов

Документ описывает поведение корневого `lab4.sh`. Этапы работы описаны в [плане проекта](plan.md), примеры запуска — в [руководстве пользователя](guide.md).

## 1. Назначение и ограничения

Программа анализирует посещаемость и результаты тестирования по данным ЛР № 3. Для запуска в Linux или Git Bash на Windows нужен Bash 4.3 или новее. Из внешних утилит скрипт вызывает только `cat`, `dirname` и `sort`.

Скрипт `lab4.sh` в корне проекта содержит меню и функции обработки данных. Он запускается командой `bash lab4.sh` без аргументов. Файл скрипта сохраняется в UTF-8 с окончаниями строк LF.

## 2. Исходные данные

Программа ищет наборы данных в папке `data/` рядом с `lab4.sh`. Каждый набор находится в отдельной папке и содержит `students/groups`. При запуске пользователь выбирает набор по номеру. Расположение `data/` определяется по пути к скрипту, поэтому запускать его можно из другой рабочей директории. Программа открывает данные только для чтения.

### Структура каталога

Ниже показан исходный набор преподавателя из ЛР № 3.

```text
data/labfiles-3-26/
├── students/
│   ├── groups/
│   │   ├── A-06-23
│   │   ├── Ae-21-23
│   │   └── …
│   └── general/
│       └── notes/
│           ├── ANames.log
│           └── …
├── Цирковое_Дело/
│   ├── A-06-23-attendance
│   ├── Ae-21-23-attendance
│   ├── …
│   └── tests/
│       ├── TEST-1
│       ├── TEST-2
│       ├── TEST-3
│       └── TEST-4
└── Пересдачеведение/
    ├── A-06-23-attendance
    ├── Ae-21-23-attendance
    ├── …
    └── tests/
        ├── TEST-1
        ├── TEST-2
        ├── TEST-3
        └── TEST-4
```

Многоточия обозначают остальные файлы того же типа. Например, состав группы `A-06-23` хранится в `students/groups/A-06-23`, а её посещаемость — в файле `A-06-23-attendance` внутри каталога соответствующего предмета. Файлы `TEST-1` … `TEST-4` общие для всех групп по этому предмету. Справочные файлы из `students/general/notes` в расчётах не участвуют.

### Форматы записей

| Путь внутри выбранного набора | Формат |
| --- | --- |
| `students/groups/<группа>` | Один логин на строку. Файл определяет состав группы для всех четырёх отчётов. |
| `<предмет>/<группа>-attendance` | Логин, один или несколько пробелов или табуляций, затем последовательность из `0` и `1`. Каждая единица обозначает посещённое занятие. Пример — `UsovPA 10110`. |
| `<предмет>/tests/<имя теста>` | Одна попытка на строку. Поля через точку с запятой — группа, логин, календарно корректная дата в формате `ГГГГ-ММ-ДД`, число правильных ответов и оценка. Пример — `A-06-23;UsovPA;2026-07-13;5;5`. |

Имена файлов в `students/groups` образуют список групп. Папка предмета находится непосредственно внутри выбранного набора и содержит каталог `tests` или хотя бы один обычный файл `*-attendance`. Папка `students` служит для списков групп и справочных данных. Каждый обычный файл в `<предмет>/tests` представляет отдельный тест. Для выбора и вывода используются имена папок предметов и файлов тестов.

Поддерживаются входные файлы UTF-8 с необязательной меткой BOM, окончаниями строк LF или CRLF и последней строкой без перевода строки. Пустые строки и строки из пробелов и табуляций пропускаются.

### Общие правила

- Студент идентифицируется по паре **группа и логин** из списков групп. Корректные записи для студентов вне этих списков пропускаются. Записи с одинаковым логином в разных группах обрабатываются отдельно.
- Оценки `3`, `4` и `5` считаются успешными. Оценка `2` считается неуспешной. Суффиксы `+` и `-` игнорируются при расчёте и выводе оценки. Например, `2++` означает 2, а `3--` означает 3.
- Каждая непустая запись файла теста соответствует отдельной попытке. Строки могут быть расположены в произвольном порядке по датам. Число правильных ответов проверяется на соответствие формату и в расчётах не используется.

## 3. Функциональные требования

### 3.1. Рейтинг посещаемости

**Вход** — группа и предмет. **Выход** — таблица с колонками «Логин» и «Посещено».

Для каждого логина из списка группы подсчитать единицы в файле посещаемости выбранного предмета. Запись из одних нулей даёт `0` посещений. Если строки студента нет, выводится «Нет записи». Повторная запись для студента из списка группы или отсутствие самого файла посещаемости считается ошибкой. Числовые результаты сортируются по убыванию числа посещений, при равенстве — по логину в побайтовом порядке. Строки «Нет записи» идут после числовых результатов в том же порядке по логину.

**Пример.** При записях `StudentA 10110` и `StudentB 00000` и отсутствии строки для `StudentC` из той же группы порядок будет таким — `StudentA — 3`, `StudentB — 0`, `StudentC — Нет записи`.

### 3.2. Студенты, не сдавшие тест

**Вход** — группа, предмет и тест из списка выбранного предмета. **Выход** — колонки «Логин» и «Статус». Строки отсортированы по логину в побайтовом порядке.

Студент считается сдавшим, если среди его попыток этого теста есть хотя бы одна положительная оценка. Остальным студентам присваивается статус **«Не сдал»**, если были только неуспешные попытки, или **«Не проходил»**, если попыток нет.

**Пример.** При оценках `2++`, `3--`, `2` студент уже сдал тест и в отчёт не попадает. При оценках `2`, `2+` его статус — «Не сдал». При отсутствии записей его статус — «Не проходил».

### 3.3. Лучшие студенты по «Цирковому делу»

**Вход** — положительное целое число `N`, по умолчанию `10`. **Выход** — до `N` студентов из всех групп. Колонки таблицы — «Место», «Логин», «Группа», «Средний балл» и «Успешных попыток» (число учтённых попыток).

Скрипт сам находит в выбранном наборе папку «Циркового дела». Для сопоставления имени он удаляет пробелы, табуляции, подчёркивания и дефисы, отбрасывает числовой суффикс и сравнивает название без учёта регистра. Например, подходят `Цирковое_Дело` и `Цирковое дело 1`. Если подходящей папки нет или их несколько, скрипт сообщает об ошибке.

Для каждого студента из списка группы учитываются все успешные попытки из всех файлов тестов «Циркового дела». Повторные успешные попытки одного теста учитываются отдельно. Средний балл равен сумме оценок, делённой на число учтённых попыток. Студенты без успешных попыток в рейтинг не входят.

Результаты сортируются по убыванию среднего балла до округления. При равенстве используется побайтовый порядок ключа `группа;логин`. Для вывода средний балл округляется до двух знаков после точки. Под строкой каждого студента выводятся тест, дата и оценка каждой учтённой попытки в порядке обработки файлов и строк внутри них.

**Пример.** Оценки по четырём тестам — `2, 3, 5`, затем `4`, затем `2, 2, 3` и затем `5`. В расчёт входят пять попыток. В строке студента выводятся средний балл `4.00` и число попыток `5`, под ней — пять строк с подробностями попыток.

### 3.4. Тесты, сданные с первой попытки

**Вход** — календарный год четырьмя цифрами от `0001` до `9999`, например `2026`. **Выход** — таблица с колонками «Логин», «Предмет», «Тест» и «Оценка».

Отчёт охватывает все предметы с файлами тестов в выбранном наборе. Для каждого студента отдельно по каждому тесту выбирается попытка с самой ранней датой. При равных датах выбирается запись, расположенная раньше в исходном файле. По этой записи проверяется успешность и совпадение года даты с запрошенным годом. Если студент сдал с первой попытки несколько тестов, каждый из них выводится отдельной строкой.

Строки сортируются в побайтовом порядке по группе, логину, предмету и тесту. Группа используется для расчёта и сортировки. Два студента с одинаковым логином из разных групп могут дать две внешне одинаковые строки.

**Пример.** В файле одного теста сначала записана попытка за `2026-01-10` с оценкой 5, а ниже попытка за `2025-12-20` с оценкой 2. Первой считается попытка за 2025 год. В отчёте за 2026 год для этого теста строки нет. Если обе записи имеют одну дату и первой в файле стоит оценка 2, тест также не считается сданным с первой попытки.

## 4. Интерфейс

### Интерактивное меню

Команда `bash lab4.sh` показывает список «Выберите набор данных». Введите номер набора, чтобы открыть главное меню, или `0`, чтобы выйти.

```text
========================================
     АНАЛИЗ УСПЕВАЕМОСТИ СТУДЕНТОВ
========================================

1. Рейтинг посещаемости
2. Студенты, не сдавшие тест
3. Лучшие студенты по Цирковому делу
4. Студенты, сдавшие с первой попытки

0. Выход

Выберите действие:
```

| Пункт | Что вводить |
| --- | --- |
| 1 | Номер группы → номер предмета. |
| 2 | Номер группы → номер предмета → номер теста. |
| 3 | Количество студентов. Пустой ввод означает `N = 10`. |
| 4 | Календарный год. |

Номера групп, предметов и тестов берутся из списков на экране. В этих списках `0` возвращает в главное меню. Пункт `0` в главном меню завершает работу. После отчёта программа показывает приглашение `Enter — вернуться в меню, 0 — выйти:`.

### Формат вывода и ошибки

Колонки всех четырёх таблиц выровнены пробелами. Если подходящих строк нет, вместо таблицы выводится сообщение. Сообщения об ошибках идут в стандартный поток ошибок. Для неверной записи указываются файл и номер строки.

Если папка `data/` недоступна или выбранный набор не прошёл начальную проверку, скрипт завершается с кодом `1`. Запуск с аргументами завершается с кодом `2` и подсказкой о запуске. Ошибки при формировании отчёта показываются в меню. При обращении к данным внутри набора скрипт отклоняет пути с символическими ссылками.
