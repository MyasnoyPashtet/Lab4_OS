# Спецификация ЛР № 4 — анализ успеваемости студентов

Документ описывает поведение актуальной версии программы. Этапы работы описаны в [плане проекта](plan.md).

## 1. Назначение и ограничения

Программа анализирует посещаемость и результаты тестирования по данным ЛР № 3. Для запуска в Linux или Git Bash на Windows нужен Bash 4.3 или новее. Из внешних утилит скрипт вызывает только `cat`, `dirname` и `sort`.

В репозитории сдачи точка входа — `lab4.sh` в корне. Меню, обработка аргументов и все функции обработки данных находятся в одном файле. Меню и CLI вызывают одни и те же функции. Файл скрипта сохраняется в UTF-8 с окончаниями строк LF.

## 2. Исходные данные

Программа читает копию исходной файловой системы преподавателя из ЛР № 3. Каталог `data/labfiles-3-26` определяется относительно `lab4.sh`. Путь остаётся одинаковым при запуске из другой рабочей директории и не задаётся через аргументы, переменные окружения или настройки. Программа не изменяет данные.

### Структура каталога

```text
data/labfiles-3-26/
├── students/
│   ├── groups/
│   │   ├── A-06-23
│   │   ├── Ae-21-23
│   │   └── …
│   └── general/
│       └── notes/
│           ├── ANames.log
│           └── …
├── Цирковое_Дело/
│   ├── A-06-23-attendance
│   ├── Ae-21-23-attendance
│   ├── …
│   └── tests/
│       ├── TEST-1
│       ├── TEST-2
│       ├── TEST-3
│       └── TEST-4
└── Пересдачеведение/
    ├── A-06-23-attendance
    ├── Ae-21-23-attendance
    ├── …
    └── tests/
        ├── TEST-1
        ├── TEST-2
        ├── TEST-3
        └── TEST-4
```

Многоточия обозначают остальные файлы того же типа. Например, состав группы `A-06-23` хранится в `students/groups/A-06-23`, а её посещаемость — в файле `A-06-23-attendance` внутри каталога соответствующего предмета. Файлы `TEST-1` … `TEST-4` общие для всех групп по этому предмету. Справочные файлы из `students/general/notes` в расчётах не участвуют.

### Форматы записей

| Путь внутри `labfiles-3-26` | Формат |
| --- | --- |
| `students/groups/<группа>` | Один логин на строку. Файл определяет состав группы для рейтинга посещаемости и списка несдавших. |
| `<предмет>/<группа>-attendance` | Логин, один или несколько пробелов или табуляций, затем последовательность из `0` и `1`. Каждая единица обозначает посещённое занятие. Пример — `UsovPA 10110`. |
| `<предмет>/tests/TEST-1` … `TEST-4` | Одна попытка на строку. Поля через точку с запятой — группа, логин, календарно корректная дата в формате `ГГГГ-ММ-ДД`, число правильных ответов и оценка. Пример — `A-06-23;UsovPA;2026-07-13;5;5`. |

Каталоги предметов ищутся непосредственно внутри `labfiles-3-26`. При сопоставлении с `Цирковое_Дело` и `Пересдачеведение` скрипт удаляет пробелы, табуляции, подчёркивания и дефисы, отбрасывает конечную последовательность цифр и приводит название к нижнему регистру. Например, `Цирковое_Дело`, `Цирковое_Дело1` и `Цирковое дело 1` распознаются как один предмет. Для каждого запрошенного предмета должен найтись ровно один каталог. При отсутствии совпадений или при нескольких совпадениях команда завершается с ошибкой.

Поддерживаются входные файлы UTF-8 с необязательной меткой BOM, окончаниями строк LF или CRLF и последней строкой без перевода строки. Пустые строки и строки из пробелов и табуляций пропускаются.

### Общие правила

- Студент идентифицируется по паре **группа и логин**. Функции 1 и 2 используют состав из файла группы. Функции 3 и 4 берут группу и логин из записей тестов. Записи с одинаковым логином в разных группах обрабатываются отдельно.
- Оценки `3`, `4` и `5` считаются успешными. Оценка `2` считается неуспешной. Суффиксы `+` и `-` игнорируются при расчёте и выводе оценки. Например, `2++` означает 2, а `3--` означает 3.
- Каждая непустая запись файла теста соответствует отдельной попытке. Строки могут быть расположены в произвольном порядке по датам. Число правильных ответов проверяется на соответствие формату и в расчётах не используется.

## 3. Функциональные требования

### 3.1. Рейтинг посещаемости

**Вход** — группа и предмет. **Выход** — таблица с колонками «Логин» и «Посещено».

Для каждого логина из списка группы подсчитать единицы в файле посещаемости выбранного предмета. Если в файле нет строки студента, вывести `0`. Корректные записи для логинов вне списка группы пропускаются. Повторная запись посещаемости для логина из списка группы считается ошибкой. Результаты сортируются по убыванию числа посещений, при равенстве — по логину в побайтовом порядке.

**Пример.** Для записей `StudentA 10110` и `StudentB 10000` рейтинг содержит `StudentA — 3`, затем `StudentB — 1`. Если `StudentC` есть в группе, но отсутствует в файле посещаемости, последней строкой будет `StudentC — 0`.

### 3.2. Студенты, не сдавшие тест

**Вход** — группа, предмет и номер теста от `1` до `4`. **Выход** — колонки «Логин» и «Статус», разделённые табуляцией. Строки отсортированы по логину в побайтовом порядке.

Студент считается сдавшим, если среди его попыток этого теста есть хотя бы одна положительная оценка. Остальным студентам присваивается статус **«Не сдал»**, если были только неуспешные попытки, или **«Не проходил»**, если попыток нет.

**Пример.** При оценках `2++`, `3--`, `2` студент уже сдал тест и в отчёт не попадает. При оценках `2`, `2+` его статус — «Не сдал». При отсутствии записей его статус — «Не проходил».

### 3.3. Лучшие студенты по «Цирковому делу»

**Вход** — положительное целое число `N`, по умолчанию `10`. **Выход** — до `N` студентов из всех групп. Колонки таблицы — «Место», «Логин», «Группа», «Средний балл» и «Успешных попыток» (число учтённых попыток).

По каждому студенту взять все успешные попытки из четырёх тестов «Циркового дела». Повторные успешные попытки одного теста учитываются отдельно. Средний балл равен сумме оценок, делённой на число учтённых попыток. Студенты без успешных попыток в рейтинг не входят.

Результаты сортируются по убыванию точного среднего балла. Дроби сравниваются перекрёстным умножением, при равенстве используется побайтовый порядок ключа `группа;логин`. Для вывода средний балл округляется до двух знаков после точки. Под строкой каждого студента выводятся тест, дата и оценка каждой учтённой попытки, в порядке номеров тестов и строк в файле каждого теста.

**Пример.** Оценки по четырём тестам — `2, 3, 5`, затем `4`, затем `2, 2, 3` и затем `5`. В расчёт входят пять попыток. В строке студента выводятся средний балл `4.00` и число попыток `5`, под ней — пять строк с подробностями попыток.

### 3.4. Тесты, сданные с первой попытки

**Вход** — календарный год четырьмя цифрами от `0001` до `9999`, например `2026`. **Выход** — таблица с колонками «Логин», «Предмет», «Тест» и «Оценка». Названия предметов в таблице — `Цирковое_Дело` и `Пересдачеведение`, обозначения тестов — от `TEST-1` до `TEST-4`.

Для каждого студента отдельно по каждому тесту обоих предметов выбрать попытку с самой ранней датой. При равных датах выбрать запись, расположенную раньше в исходном файле. По этой записи проверить успешность и совпадение года даты с запрошенным годом. Если студент сдал с первой попытки несколько тестов, вывести каждый из них.

Строки сортируются в побайтовом порядке по группе, логину, предмету и тесту. Группа используется для расчёта и сортировки. Два студента с одинаковым логином из разных групп могут дать две внешне одинаковые строки.

**Пример.** В файле одного теста сначала записана попытка за `2026-01-10` с оценкой 5, а ниже попытка за `2025-12-20` с оценкой 2. Первой считается попытка за 2025 год. В отчёте за 2026 год для этого теста строки нет. Если обе записи имеют одну дату и первой в файле стоит оценка 2, тест также не считается сданным с первой попытки.

## 4. Интерфейс

### Интерактивное меню

Команда `bash lab4.sh` открывает главное меню.

```text
========================================
     АНАЛИЗ УСПЕВАЕМОСТИ СТУДЕНТОВ
========================================

1. Рейтинг посещаемости
2. Студенты, не сдавшие тест
3. Лучшие студенты по Цирковому делу
4. Студенты, сдавшие с первой попытки

0. Выход

Выберите действие:
```

| Пункт | Подсказки в порядке ввода |
| --- | --- |
| 1 | `Группа (например, A-06-23 или Ae-21-23, A и e латинские):` → `Предмет (1 — Цирковое дело, 2 — Пересдачеведение):` |
| 2 | Те же подсказки, затем `Номер теста (1–4):` |
| 3 | `Количество студентов [10]:` Пустой ввод означает `N = 10`. |
| 4 | `Календарный год:` |

Пункт `0` сразу завершает работу. После вывода результата программа показывает приглашение `Enter — вернуться в меню, 0 — выйти:`.

### Общие параметры и формат вывода

- В функциях 1 и 2 предмет выбирается цифрой `1` для «Циркового дела» или `2` для «Пересдачеведения». В меню и CLI также принимаются названия, например `Цирковое_Дело` или `Цирковое дело`. В командной строке название с пробелами передаётся в кавычках. Названия сопоставляются по тем же правилам, что и имена каталогов.
- Имя группы должно точно совпадать с именем файла в `students/groups`, включая регистр. В `A-06-23` и `Ae-21-23` буквы `A` и `e` латинские.
- Колонки таблиц функций 1, 3 и 4 выровнены пробелами.

### Командная строка

Выполняйте команды из корня репозитория сдачи.

```bash
bash lab4.sh attendance A-06-23 1
bash lab4.sh attendance A-06-23 "Цирковое дело"
bash lab4.sh failed A-06-23 2 2
bash lab4.sh top
bash lab4.sh top 5
bash lab4.sh first-attempt 2026
bash lab4.sh --help
```

Справка показывает команды и параметры. В CLI код `0` означает успешное выполнение. Если подходящих строк нет, вместо таблицы выводится сообщение. Код `2` означает неверные аргументы, код `1` — ошибку данных или выполнения, в том числе неизвестную группу или неоднозначный каталог предмета. Ошибки выводятся в стандартный поток ошибок. Для неверной записи указываются файл и номер строки.
