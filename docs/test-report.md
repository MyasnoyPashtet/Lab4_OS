# Отчёт о тестировании ЛР № 4

Дата проверки — 12.11.2026. Повторное тестирование выполнено для `lab4.sh` из коммита `621452a`. Среда выполнения — Git Bash на Windows, GNU Bash 5.3.15(1).

## Данные и способ проверки

Для 60 кейсов использовали синтетический набор из `tests/data/synthetic/labfiles-3-26`. Он повторяет структуру данных преподавателя. В нём есть пустая группа, одинаковые логины в разных группах, нулевая посещаемость и отсутствие записи о посещении. В файлах тестов есть успешные пересдачи, несколько попыток в один день и попытки в разных календарных годах. Ещё четыре кейса проверяют отчёты на данных преподавателя из `data/labfiles-3-26`.

Автотесты запускали из корня проекта.

```bash
bash tests/run-tests.sh
bash tests/run-tests.sh --real
```

Для каждого кейса `tests/run-tests.sh` создавал временную копию скрипта и нужных данных, запускал программу из другой рабочей директории и передавал ответы в меню через стандартный ввод. Скрипт проверки сверял вывод, сообщения об ошибках и код завершения. На каждый запуск `lab4.sh` отводилось 20 секунд. Подготовка данных, шаги и фактические результаты по каждому ID приведены в [тест-кейсах](../tests/test-cases.md).
