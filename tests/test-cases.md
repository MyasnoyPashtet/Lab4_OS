# Тест-кейсы ЛР № 4

Из корня проекта выполните:

```bash
bash tests/run-tests.sh
bash tests/run-tests.sh --real
```

Первый запуск выполняет 60 кейсов на синтетическом наборе. Ключ `--real` добавляет четыре проверки на данных преподавателя из `data/labfiles-3-26`. Для каждого кейса создаётся отдельная временная копия скрипта и нужных данных. Варианты с изменёнными файлами готовятся в этой копии. После запуска состояние данных сверяется со снимком, сделанным перед запуском.

В таблицах `1 / 2 / …` означает ввод значений по одному на строку, `Enter` — пустую строку. Первый номер выбирает набор, второй — действие. Номера групп, предметов и тестов воспроизводимы благодаря `LC_ALL=C`. После отчёта `0` завершает работу, `Enter` возвращает в меню. Ошибка отчёта выводится в stderr. В таблицах для неё подразумевается код процесса `0`, если пользователь затем штатно вышел.

## Контрольные данные

Синтетический набор повторяет структуру архива преподавателя. Логины, оценки и остальные записи составлены для проверок.

```text
tests/data/synthetic/labfiles-3-26/
├── students/
│   ├── groups/
│   │   ├── A-06-21
│   │   ├── A-06-23
│   │   └── Ae-21-23
│   └── general/notes/ANames.log
├── Пересдачеведение/
│   ├── A-06-23-attendance
│   └── tests/TEST-1 … TEST-4
└── Цирковое_Дело/
    ├── A-06-21-attendance
    ├── A-06-23-attendance
    ├── Ae-21-23-attendance
    └── tests/TEST-1 … TEST-4
```

Группа `A-06-21` пуста. `SokolovSS` встречается в двух группах, `UnknownUU` отсутствует в списках. У `VolkovVV` нулевая посещаемость, у `AntonovAV` нет записи о посещаемости по «Цирковому делу». У `AlekseevAA` успешная пересдача окружена двойками, даты записаны не по порядку. У `SokolovSS` из `A-06-23` две попытки одного теста в один день, первая строка содержит двойку. `TEST-3` по «Цирковому делу» пуст.
