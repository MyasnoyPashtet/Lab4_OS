# Тест-кейсы ЛР № 4

## Как проводили тестирование

Проверку выполнили 12.11.2026 на версии `lab4.sh` из коммита `621452a`. SHA-256 проверенного файла совпал до и после прогонов.

```text
4423a51e5e87974d085358bab7914f8523e581805aed7a743bc5cdbcf3586d01
```

Команды запускали из корня проекта.

```bash
bash tests/run-tests.sh
bash tests/run-tests.sh --real
```

Первый запуск выполняет 60 кейсов на синтетическом наборе. Ключ `--real` добавляет четыре проверки на данных преподавателя из `data/labfiles-3-26`. Для каждого кейса `tests/run-tests.sh` создавал отдельную временную копию `lab4.sh` и нужных данных. Варианты с изменёнными файлами готовили в этой копии. Тестовый скрипт запускал `lab4.sh` из другой рабочей директории, передавал ответы через стандартный ввод и сверял код завершения, строки отчётов и сообщения об ошибках. После запуска он сравнивал данные со снимком и проверял, что копия `lab4.sh` совпадает с оригиналом.

В таблицах `1 / 2 / …` означает ввод значений по одному на строку, `Enter` — пустую строку. Первый номер выбирает набор, второй — действие. Номера групп, предметов и тестов воспроизводимы благодаря `LC_ALL=C`. После отчёта `0` завершает работу, `Enter` возвращает в меню. Ошибка отчёта выводится в stderr. В таблицах для неё подразумевается код процесса `0`, если пользователь затем штатно вышел.
