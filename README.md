# ЛР 4 — Скрипты для файловой системы преподавателя

Решение на Bash для обработки данных о посещаемости и результатах тестирования студентов из файловой системы ЛР №3.

**Заказчик:** Емельянов Д. М.

## Функциональность

| Функция | Описание |
|---|---|
| Рейтинг посещаемости | Список студентов заданной группы, упорядоченный по количеству посещённых занятий по выбранному предмету. |
| Несдавшие тест | Список студентов заданной группы, не сдавших выбранный тест по заданному предмету, включая студентов без попыток. |
| Лучшие студенты | Топ-N студентов среди всех групп по среднему баллу успешных попыток всех тестов по предмету «Цирковое дело» (по умолчанию N = 10). |
| Сдача с первой попытки | Список всех успешных первых попыток тестов по обоим предметам за заданный календарный год с указанием студента, группы, предмета, теста, даты и оценки. |
